# MVP Scope

## Phase 1 — Public Website
- Home
- About
- Products
- Product detail
- Therapeutic Areas
- Quality
- R&D
- News
- Careers
- Contact

## Phase 2 — Admin
- authentication
- dashboard
- products CRUD
- categories CRUD
- therapeutic areas CRUD
- news CRUD
- careers CRUD
- applications
- certifications
- contact messages
- homepage content
- site settings

## Phase 3 — Polish
- animation
- SEO metadata
- sitemap
- analytics-ready integration
- image optimization
- accessibility review
- responsive QA
- empty/loading/error states

## Not Required in MVP
- ERP integration
- distributor portal
- online pharmacy checkout
- prescriptions
- patient records
- medical consultation
- multi-tenant architecture
