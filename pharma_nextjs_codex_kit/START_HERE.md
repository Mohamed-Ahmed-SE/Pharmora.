# Pharmaceutical Website — START HERE

This project is a premium pharmaceutical corporate website and CMS built with Next.js.

## Goal
Build an international-looking pharmaceutical website that feels trustworthy, scientific, modern, and premium — not like a generic medical template.

## Core Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- PostgreSQL
- Prisma ORM for schema, migrations, and database access
- Better Auth for secure admin authentication and sessions
- Cloudinary for product, news, certification, and other public media
- Framer Motion for subtle animation only
- Zod for validation
- React Hook Form where useful
