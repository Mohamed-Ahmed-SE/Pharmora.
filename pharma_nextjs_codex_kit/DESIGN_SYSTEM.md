# Design System

## Visual Direction
Premium international pharmaceutical company.

The supplied reference image is the mood/reference direction only.
Keep:
- white/light backgrounds
- aqua/teal medical accents
- medical/lab photography
- clean modular sections
- stats
- research/news blocks
- strong footer structure

Improve:
- stronger typography
- better spacing
- more premium composition
- flatter cards
- better product presentation
- better mobile behavior
- fewer template-like blocks

## Colors

### Core
- Background: `#F8FBFC`
- Surface: `#FFFFFF`
- Primary Navy: `#09243A`
- Medical Blue: `#1769AA`
- Aqua Accent: `#31C7C5`
- Light Aqua: `#EAF8F7`
- Main Text: `#17212B`
- Muted Text: `#667581`
- Border: `#DDE7EA`

### Status
- Success: `#2F8F6B`
- Warning: `#C68A2B`
- Error: `#C84D4D`

## Typography
Preferred:
- Headings: Manrope
- Body/UI: Inter

Alternative:
- Headings: Plus Jakarta Sans
- Body/UI: Inter

## Typography Scale
- Hero: clamp(3rem, 6vw, 6.5rem)
- H1: clamp(2.5rem, 5vw, 5rem)
- H2: clamp(2rem, 4vw, 3.75rem)
- H3: 1.5rem–2rem
- Body large: 1.125rem
- Body: 1rem
- Small: 0.875rem

## Layout
- Max width: 1440px
- Main content width: 1280px
- Horizontal padding: 24px mobile / 40px tablet / 64px desktop
- Section spacing: 88–140px desktop
- Grid: 12-column desktop

## Buttons
Primary:
- navy or aqua background
- high contrast
- medium radius
- no glow

Secondary:
- white or transparent
- 1px border
- clear hover state

## Cards
- subtle 1px border
- white or soft tinted background
- minimal shadow
- radius 16–20px
- no glassmorphism

## Images
Use:
- pharmaceutical manufacturing
- scientists
- laboratories
- quality-control environments
- packaging/product imagery

Avoid:
- generic smiling doctor stock photos unless contextually appropriate
- AI-looking medical imagery
