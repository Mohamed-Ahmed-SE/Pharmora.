# SEO, Performance, Accessibility

## SEO
Every public page must support:
- title
- description
- canonical
- Open Graph metadata
- Twitter metadata where appropriate

Generate:
- sitemap.xml
- robots.txt

Use structured data where valid:
- Organization
- BreadcrumbList
- Article for news
- JobPosting for careers

Do not make unsupported medical structured-data claims.

## Product SEO
Each product:
`/products/[slug]`

Each therapeutic area:
`/therapeutic-areas/[slug]`

Each news article:
`/news/[slug]`

## Performance Targets
Desktop:
- Performance 95+
- Accessibility 95+
- Best Practices 95+
- SEO 95+

Mobile:
- Performance 90+
- Accessibility 95+
- Best Practices 95+
- SEO 95+

These are targets, not fake guarantees.

## Performance Rules
- next/image
- proper sizes attribute
- AVIF/WebP where supported
- lazy-load below-the-fold media
- no autoplay background video on mobile unless heavily optimized
- server components by default
- avoid giant JS animation bundles
- font optimization
- dynamic imports for heavy components
- no unnecessary UI libraries

## Accessibility
- semantic landmarks
- keyboard navigation
- visible focus states
- contrast compliance
- alt text
- form labels
- error summaries
- reduced-motion support
