# Admin Dashboard

## Design Direction
The admin is a separate visual system from the public website.

Use a clean premium SaaS-style dashboard:
- compact sidebar
- top utility bar
- clean data tables
- clear forms
- restrained colors
- no decorative gradients
- excellent responsive behavior
